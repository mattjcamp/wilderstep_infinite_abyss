# Dungeon Config

**Superseded by [Dungeon](dungeon.md).**

This was a TBD placeholder for the procedural-dungeon generator's input parameters back when Dungeon was framed as an *authored* multi-level model. The Dungeon model has since pivoted to procedural generation itself — it now carries `style`, `difficulty`, `size`, `torch_density`, and `locked_doors` as the generator's defaults, with per-floor overrides on each inline [Dungeon Level](dungeon_level.md).

Nothing remains for "Dungeon Config" to mean as a separate model. Safe to delete this file when convenient.
